# പ്രായപൂർത്തിയായവർക്കുള്ള വീഡിയോയ്ക്ക് എൻക്രിപ്ഷൻ എന്തുകൊണ്ട് ആവശ്യമാണ്?

പ്രായപൂർത്തിയായവർക്കുള്ള വീഡിയോ മേഖലയിൽ പൈറസി വ്യാപകമാണ്. പണമടച്ച ഉള്ളടക്കം ഡൗൺലോഡ് ചെയ്യപ്പെടാനും ഫോർവേഡ് ചെയ്യപ്പെടാനും സ്ക്രീൻ റെക്കോർഡ് ചെയ്യപ്പെടാനും വീണ്ടും വിൽക്കപ്പെടാനും സാധ്യതയുണ്ട്. LockBox വീഡിയോ എൻക്രിപ്ഷൻ, ഉപകരണ അനുമതി, കാലാവധി, പ്ലേ പരിധി, ഓഫ്ലൈൻ അനുമതി എന്നിവ നൽകി വരുമാനവും ഡിജിറ്റൽ ആസ്തിയും സംരക്ഷിക്കുന്നു.
